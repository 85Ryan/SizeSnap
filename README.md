# SizeSnap 快窗

记住顺手的窗口布局。保存 Chrome 窗口的尺寸和位置，随时一键恢复。

一个可直接加载的 Manifest V3 扩展，无运行时依赖、无账号、无远程服务。

插件仅供本地使用，不上架商店，也不再生成 ZIP 安装包。`extension/` 是仓库里的插件源码，`dist/` 是本机 Chrome 的加载目录。修改源码后运行 `npm run build`，再在 Chrome 中重新加载扩展。

## 安装使用

1. 在 Chrome 地址栏输入 `chrome://extensions`。
2. 打开右上角的「开发者模式」。
3. 点击「加载已解压的扩展程序」，选择本项目中的 **dist** 文件夹（其下直接包含 `manifest.json`）。
4. 在工具栏的「扩展程序」菜单中，将「SizeSnap 快窗」固定。
5. 把 Chrome 窗口调整到喜欢的大小和位置，点击快窗图标，再点「保存当前窗口」。
6. 后续点击对应预设名称，即可恢复当前窗口。

**当前工作区已经生成 dist，可直接加载；从远程仓库克隆后先运行 `npm run build`。**构建脚本只复制插件运行文件，不生成安装包。

首次从旧的项目根目录或 `dist/SizeSnap-1.1.0` 切换到 `dist` 时，先在旧插件中「导出」预设，再加载 `dist`，在新插件中「导入」。加载路径变化可能使 Chrome 使用不同的扩展 ID，本地预设不会自动跨 ID 迁移。确认迁移成功后可停用旧插件，避免工具栏出现两个快窗。

之后固定使用 `dist`。修改 `extension/` 后运行 `npm run build`，在 `chrome://extensions` 点击快窗的「重新加载」，再重新打开面板即可看到修改，当前插件的预设会保留。无需重复添加扩展。旧版解压目录和 ZIP 在本机保留为迁移备份，不参与开发。根目录原来的运行入口是指向 dist 的本地符号链接，仅供旧安装兼容，不提交到仓库。

## 功能

- 保存当前窗口的外框尺寸、桌面坐标和普通 / 最大化 / 全屏状态。
- 多个命名预设，点击即恢复；支持重命名、编辑和删除确认。
- 自定义宽度、高度、X / Y 坐标；支持副屏负坐标。
- 快捷尺寸：16:9（2560×1440）、4:3（2560×1920）、3:2（2400×1600）、16:10（2560×1600）、1:1（2560×2560）。
- 一键在当前窗口所在显示器的可用区域居中，开启后修改尺寸会同步更新坐标。
- 不创建预设也可以直接应用尺寸与位置。
- 每个窗口分别记录上一次调整，可一键撤销；关闭浏览器后清除撤销记录。
- 显示器位置变化时保留相对位置；原显示器断开时迁移到当前窗口所在屏幕，并限制到可见工作区。
- 预设持久保存在本机，支持 JSON 导出和合并导入，最多 100 个预设。
- 独立的预设编辑视图，固定底部操作，当前匹配预设标记；浅色 / 深色主题跟随系统。
- 键盘操作、可见焦点、可关闭的状态提示，以及返回时的未保存修改确认。
- 调整由后台 Service Worker 完成，即使面板因移动窗口而关闭也会继续执行。

## 快捷尺寸与居中

快捷尺寸以约 2560 像素宽度为基准，其中 3:2 采用 2400×1600，保持精确比例。打开「自定义预设」，点击一个比例会填入具体宽高；名称为空时也会建议一个名称，不会直接移动窗口或自动保存。输入已有名称时会保留名称。尺寸按窗口外框计算，不是网页内容的宽高比。

点击「屏幕居中」后，会以当前 Chrome 窗口所在显示器的可用工作区计算坐标，避开菜单栏与 Dock。按钮会显示「保持居中」，此时调整尺寸或选择其他比例都会重新计算坐标。再次点击按钮，或手动修改 X / Y，即可退出持续居中。

点击「保存预设」保存配置，或点击「仅应用尺寸与位置」立即试用。比例与居中操作默认切换为普通窗口；最大化和全屏的最终尺寸由系统决定。超出工作区的尺寸在应用时仍会自动适配，原始预设不变。

## 快捷键

默认用 `⌘⇧Y`（macOS）或 `Ctrl+Shift+Y`（Windows / Linux）打开快窗。如果与其他扩展冲突，可以自行修改。

在 `chrome://extensions/shortcuts` 中，还可以为以下动作设置快捷键：

- 保存当前窗口为新预设。
- 恢复最近使用的预设（尚未恢复过时，使用最近保存的预设）。
- 撤销上一次窗口调整。

快捷键执行成功时，图标显示 `✓`；出错时显示 `!`，重新打开面板可查看结果。

## 尺寸与系统行为

- 尺寸包含标签栏、地址栏和窗口边框，不是网页内容区域尺寸。
- 坐标和尺寸使用 Chrome 窗口 API 返回的像素值；Retina / HiDPI 下不等同于截图的物理像素。
- 仅调整调用它的普通 Chrome 浏览器窗口，不操作其他应用，也不改动标签页内容。
- 这是一枚工具栏扩展，不会向截图中的 macOS 原生「窗口」菜单插入菜单项。
- 超出当前屏幕工作区的预设会自动缩小或移入屏幕，保留原始预设数据。Chrome 和操作系统也可能限制最小尺寸；面板会提示调整。
- macOS 全屏切换涉及系统 Space 动画。扩展会先退出全屏，再恢复几何位置和保存的状态；若系统未及时完成切换，会提示重试。
- 不能指定或恢复 macOS 的某个桌面 Space，也不记录网页会话。原生平铺关系不会保存。
- 最大化 / 全屏预设保存的是该状态下可读取的边界，Chrome API 不提供其隐藏的普通窗口尺寸。
- 预设不会跨设备自动同步。卸载扩展会清除本地数据，建议先导出备份。

## 权限与隐私

只申请 `storage` 和 `system.display`：前者存储预设，后者读取显示器工作区以避免窗口移出屏幕。

不申请 `tabs`、网页访问或浏览历史权限，没有内容脚本，不读取页面标题 / URL / 正文，不上传任何数据。快捷键设置入口通过 `chrome.tabs.create` 打开 Chrome 内置页面，此操作不需要 `tabs` 权限。

实现参考 [Chrome Windows API](https://developer.chrome.com/docs/extensions/reference/api/windows)、[System Display API](https://developer.chrome.com/docs/extensions/reference/api/system/display)。

## 开发与验证

构建、检查和测试要求 Node.js 20+；图标生成脚本使用 Python 3 标准库。插件运行不需要开发依赖。

```sh
npm run build             # 将 extension/ 同步到本机 dist/
npm test                  # 核心逻辑测试，不需要安装依赖
npm run check             # 检查 extension/ 中的 Manifest、权限、图标、CSP、脚本语法
```

浏览器测试需要开发依赖 Playwright 和其测试浏览器：

```sh
npm ci
npx playwright install chromium
npm run test:browser      # 独立临时配置，直接加载 dist 并调用 Chrome API
HEADED=1 npm run test:browser  # macOS / Linux 可见窗口测试
```

测试仅使用独立的临时浏览器配置，完成后会关闭测试浏览器并删除测试配置。截图在 `test-results/`，不混入运行目录。`dist/`、`node_modules/` 和测试截图均被 Git 忽略。可通过 `CHROME_PATH` 指定支持加载扩展的 Chromium / Chrome for Testing 可执行文件。

核心测试覆盖多显示器、负坐标、显示器断开和移动、参数校验、存储并发、窗口状态转换、撤销、导入合并及失败恢复。浏览器测试覆盖真实扩展加载、保存、编辑、移动与缩放、撤销、导入导出、删除、重启持久化、界面渲染和发送页面关闭后后台完成操作。

实际外接屏热插拔与 macOS 全屏 Space 动画仍建议在目标机器上手动验收；自动化中的状态及显示器边界测试不能替代所有系统环境。

## 文件结构

```text
extension/              Git 提交的插件源码
  manifest.json         扩展入口、权限、命令
  popup.html            工具栏面板
  src/                  交互、样式与窗口恢复逻辑
  icons/                品牌图标及本地 UI 图标
dist/                   本机 Chrome 加载目录，由构建脚本生成，整体忽略
scripts/                构建、检查和图标生成工具
tests/                  核心和浏览器测试
docs/                   设计说明
```

界面图标来自 Phosphor regular，本地素材及 MIT 许可证位于 `extension/icons/ui/`。品牌图标源文件为 `extension/icons/mark.svg`，工具栏 PNG 由 `scripts/generate-icons.py` 生成。安装开发依赖后可运行 `npm run icons` 更新图标素材。设计约定与验收记录见 [docs/DESIGN.md](docs/DESIGN.md)。

后续修改直接编辑 `extension/`。完成后运行 `npm run build`，在 `chrome://extensions` 点击快窗的「重新加载」，再打开面板。构建不影响保存在 Chrome 本机存储中的预设。
